## 1. 实际控制速度的参数

源码：`src/peripherals/peripherals/joystick_control.py`。
启动文件：`src/peripherals/launch/joystick_control.launch.py`。

| 参数 | 默认值 | 配置范围（含端点） | 作用 |
|---|---:|---:|---|
| `joint_step` | `10` | 整数 `1..20` | 每次关节点动的舵机位置增量，单位 pulse，不是角度 |
| `joint_duration` | `0.05` | 浮点 `0.02..30.0` | 每条关节点动指令的运动时间，秒 |
| `cartesian_step` | `0.005` | 浮点 `0.0001..0.01` | 笛卡尔模式每次 x/y/z 位移，米；默认 5 mm |
| `cartesian_duration` | `0.02` | 浮点 `0.02..30.0` | IK 求解结果下发到舵机时的运动时间，秒 |
| `pitch_step` | `1.0` | 浮点 `0.1..2.0` | 笛卡尔模式每次俯仰增量，度 |

这些是本次配置校验边界，不是厂家额定速度、关节安全角度或无碰撞保证。时间范围匹配现有下层控制器对指令时间的限制；步长上限有意限制为原默认值的两倍。参数必须有限、类型正确；不合法参数在创建运动发布器和发送初始化姿态前报错。直接 `ros2 run` 时，时间及笛卡尔步长应写成浮点形式，例如 `0.1`、`1.0`，不要写整数 `1`。

- **单舵机模式 `mode=0`**：方向键、L1/L2、R1/R2、方块/圆圈/叉/三角的关节点动都使用 `joint_step` 和 `joint_duration`，包括夹爪。
- **笛卡尔模式 `mode=1`**：方向键及 L1/L2 使用 `cartesian_step`，R1/R2 使用 `pitch_step`；IK 输出使用 `cartesian_duration`。方块/圆圈/叉/三角仍是关节点动，使用关节参数。
- 舵机 ID、按键方向、模式切换、初始化姿态和 START 回中动作均未修改。
- 笛卡尔模式依赖原有可用的 FK/IK 服务。此次参数化不修复不兼容的 `.so`，也不证明运动学服务已通过实机验证。

## 2. 如何理解“变慢/变快”

**先减小 `joint_step`，适合更细的小步操作；同一目标距离下，增加 `joint_duration` 会放宽单条运动指令的完成时间。** 调快时可小幅增大步长，先保持时间不变观察。

例如 `joint_step=5, joint_duration=0.1` 表示每次关节点动目标变化 5 个位置单位，指令运动时间 0.1 秒；不是让整臂保证以固定比例或固定角速度运动。

程序通过 pygame 事件触发动作。2026-10-27 后续排障已修复输入回调中的无限循环，现在每 0.1 秒处理一批事件后返回，以便舵机状态订阅正常运行。

- 0.1 秒是检查输入的周期，不表示按住按键就固定每秒发送 10 次动作。
- 当前为事件点动，不自动长按重复。每次按下/十字键方向变化触发一次，释放不新增动作；它不会主动停止已经下发的目标运动。
- 连续短按可能在上一目标完成前发出下一目标；`步长 ÷ 指令时间` 不是实测整臂速度。
- 先短按一个键观察；Ctrl+C 不保证已经发出的动作立即停止。

## 5. 生效方式与常见误区

- `joint_step` 与 `joint_duration` 现支持运行时更新；推荐使用监视窗口一次提交两项参数。其他笛卡尔参数仍标记为 `read_only`，需要重启。升级前已运行的旧手柄节点需先重启一次才能获得新功能。
- launch 命令显式提供的参数覆盖 launch 默认值；直接 `ros2 run --ros-args -p ...` 覆盖节点声明默认值。`config/pc.env` 不会自动读取这些新增参数。
- launch 中旧的 `max_linear`、`max_angular` 没有被这个机械臂程序使用，改它们不能调节本次的机械臂点动速度。保留旧参数以减少对已有启动命令的影响。
- 原 `disable_servo_control=True` 也不是此程序的有效禁动开关，不可把它当作安全保护。
- 在本机已有 symlink 安装的情况下，新进程会加载更新源码；已经运行的进程不会自动更新。本次已重新构建 `peripherals`。其他设备重新部署时，先在依赖已构建的环境运行：

```bash
cd /你的/ros2_ws
source scripts/setup_pc.bash
colcon build --base-paths src/peripherals --packages-select peripherals --symlink-install
source scripts/setup_pc.bash
```

只查看 launch 参数、不启动节点：

```bash
ros2 launch peripherals joystick_control.launch.py --show-args
```

限定 `--base-paths src/peripherals` 是为了只发现此次修改的包，避免从仓库根目录扫描 `software/ultralytics` 等不相关软件。
